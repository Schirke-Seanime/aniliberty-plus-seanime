<h1 align="center">AniLiberty+ for Seanime</h1>

<p align="center">
  <a href="https://anilibria.top">AniLibria / AniLiberty</a> extensions for <a href="https://github.com/5rahim/seanime">Seanime</a>.<br>
  Russian dubs, with the right season picked automatically.
</p>

---

- **AniLiberty+ Online** — online streaming in 1080p / 720p / 480p. New episodes are available as soon as they're on the site.
- **AniLiberty+** — torrent provider with a working Smart search: the right season is matched by MAL ID and torrents are filtered by episode.

## Installation

In Seanime, open **Extensions** → **Add extension** and paste the manifest URL. The extensions are independent, install either or both.

**AniLiberty+ Online** (*Online streaming* tab):
```
https://raw.githubusercontent.com/Schirke/aniliberty-plus-seanime/main/online/manifest.json
```

**AniLiberty+** (*Torrent streaming* tab, turn **Smart search** on):
```
https://raw.githubusercontent.com/Schirke/aniliberty-plus-seanime/main/src/manifest.json
```

If you have the original **AniLiberty** extension installed, disable it to avoid duplicate torrents.
