# AniLiberty+ для Seanime

Провайдер торрентов [AniLibria / AniLiberty](https://anilibria.top) для [Seanime](https://github.com/5rahim/seanime)
с работающим **Smart search**. Русская озвучка, торрент-стриминг прямо из Seanime.

## Установка

Seanime → **Extensions** → **Add extension** → вставить ссылку на манифест:

```
https://raw.githubusercontent.com/Schirke/aniliberty-plus-seanime/main/src/manifest.json
```

Затем в окне выбора торрента выбрать провайдер **AniLiberty+** и включить **Smart search**.
Если у вас стоит исходный AniLiberty, его лучше отключить, чтобы не было дублей при поиске по всем провайдерам.

## Чем отличается от исходного расширения

Основано на [vsecoder/AniLiberty-Seanime](https://github.com/vsecoder/AniLiberty-Seanime), провайдер переписан.

- **Smart search работает.** В исходнике он был заглушкой и возвращал пустой список.
- **Сезон определяется по MAL ID.** Каждый релиз AniLibria сопоставляется с тайтлом AniList по MAL ID,
  поэтому сезоны одного тайтла (Dr. Stone, Dr. Stone: Stone Wars, New World…) больше не смешиваются.
- **Название ищется несколькими вариантами:** romaji, английское, синонимы и базовое название без сезона.
  Поиск AniLibria плохо находит английские названия: «The Apothecary Diaries» даёт 0 результатов,
  а «Kusuriya no Hitorigoto» находится. Раньше из-за этого часть тайтлов «не находилась».
- **Фильтр по номеру серии.** AniLibria часто делит сезон на несколько раздач (например `1-13` и `14-24`);
  для 20-й серии показываются только раздачи, в которые она входит.
- Диапазон серий, качество и кодек видны в названии раздачи: `Dr. Stone [14-24][WEBRip 1080p x264/AVC]`.
- Фильмы и OVA не помечаются как batch.
- Если по выбранному качеству ничего нет, показываются все раздачи, а не пустой список.

## Ограничения

AniLibria озвучивает не все тайтлы. Если релиза нет на anilibria.top, провайдер ничего не найдёт —
для таких тайтлов включайте «Search across providers», чтобы подтянулись другие источники (например Nyaa).
